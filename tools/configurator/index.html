Load the configuration

  • Open SD card folder - connect the switched-off device over USB, choose the top folder of the SD card drive. Changes are saved straight to the card (Chrome or Edge).
  • Connect via Bluetooth - device switched on, UltraBeep firmware (Chrome or Edge).
  • New config - no device at hand: the defaults with three example profiles and every view of the configurator (the ones that need a device say so). Saving downloads config.ultrabip (top folder of the SD card) and config_ext.ultrabip (folder ultrabeep).

Profiles 1-3 stay in config.ultrabip (also editable with BipLink); profiles 4-10 and the new settings go into ultrabeep/config_ext.ultrabip (a folder, because the stock firmware deletes unknown files in the top folder). Lines this page does not know are kept.

View (header): Basic shows the everyday settings, Expert adds the fine tuning such as the takeoff thresholds, Developer everything - sampling rates, the raw log, Status and tests and the config files as text.
